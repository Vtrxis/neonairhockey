# Neon Air Hockey

Neon Air Hockey é um jogo arcade inspirado em Air Hockey com visual neon, efeitos sonoros e multiplayer local para dois jogadores.

---

# Especificações

O jogo foi desenvolvido utilizando a IDE Processing (Java).

---

# Jogabilidade

## PLAYER 1 (VERDE)

* W → cima
* A → esquerda
* S → baixo
* D → direita

## PLAYER 2 (ROXO)

* ↑ → cima
* ↓ → baixo
* ← → esquerda
* → → direita

---

# Requisitos

* Processing IDE (Java)
* Biblioteca Minim instalada

A biblioteca Minim é responsável pelos efeitos sonoros do jogo.

---

# Como executar

1. Instale o Processing IDE
2. Instale a biblioteca Minim:

   * Abra o Processing
   * Vá em `Sketch → Import Library → Add Library`
   * Pesquise por `Minim`
   * Clique em `Install`
3. Abra o arquivo `neonairhockey.pde`
4. Clique em `Run`
